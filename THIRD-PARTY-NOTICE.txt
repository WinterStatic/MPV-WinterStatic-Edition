Third-party notice
==================

MPV WinterStatic Edition uses libmpv from the mpv media player project as its
playback engine. The Full Portable build also contains FFmpeg and supporting
runtime libraries collected from the builder's MSYS2 MINGW64 installation.

These third-party components are not relicensed by MPV WinterStatic Edition. They
retain the licenses of their respective projects/packages. The portable build
places them under libmpv\ and generates:

  RUNTIME-MANIFEST.txt   exact DLL -> MSYS2 package/version provenance
  RUNTIME-PACKAGES.tsv    binary package -> MSYS2 source package mapping
  licenses\              installed license files collected from those packages

The MSYS2 MINGW64 mpv package used by this build family is distributed as
GPL-2.0-or-later, and its FFmpeg dependency is distributed as
GPL-3.0-or-later at the time of the 0.4.10 preparation. Because the Full
Portable package conveys those binaries together with this frontend, MPV
WinterStatic Edition's frontend is released under GPL-3.0-or-later.

IMPORTANT FOR PUBLIC BINARY RELEASES
------------------------------------
Redistributors are responsible for satisfying the applicable source-code and
notice obligations for the exact binaries they convey. Keep this notice, the
runtime manifest/package mapping, collected license files, and the project
LICENSE. For public Full Portable releases, `build-native.bat release` invokes
the 0.4.10 source collector, which downloads the exact official MSYS2 Source-Only
Tarballs for every represented runtime package. Attach that matching source
bundle to the same release. See PUBLIC-RELEASE-CHECKLIST.md in the source
repository.

MPV WinterStatic Edition is independently developed and does not contain MPC-QT
source code.
